# TraderWeb

Standalone React storefront for the Laravel marketplace API.

## Pages

- Home
- Categories
- Products
- Product detail
- Stores
- Store detail

## Local usage

1. Make sure the Laravel app is running.
2. Copy `.env.example` to `.env` if you need to change the backend URL.
3. Run `npm run dev` inside `traderweb`.
4. Build with `npm run build`.

The app uses the public Laravel APIs described in `docs/daraz-like-marketplace-project.md` and links to the generated developer docs at `/docs/api`.
